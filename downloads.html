macOS

Installation guide

ClimaxDJ 4.7.0 for Mac is the same full app, shipped as architecture-specific zips. Choose the chip that matches your Mac, then follow Gatekeeper steps — the app is not Apple-signed.

Which version?

Apple Silicon vs Intel

  • Apple Silicon (M1, M2, M3, M4, M5, M6) → arm64 zip
  • Intel Mac → x64 zip

How to check: Apple menu → About This Mac → Chip (Apple M…) or Processor (Intel).

↑ Get the Mac build

Requirements

macOS 11+

Built with Electron 33.2.1 — macOS Big Sur (11) and up. No universal binary (separate arm64 / x64 zips).

Not Developer ID signed · not notarized · cross-built from Linux. Early preview — feedback welcome.

Install steps

Download the zip

Get the arm64 or x64 zip for your Mac from the macOS card above (~92–96 MB).

Unzip

Double-click the zip. You should see ClimaxDJ.app.

Move to Applications

Drag ClimaxDJ.app into the Applications folder.

First launch (Gatekeeper)

Right-click ClimaxDJ.app → Open → confirm Open. Or System Settings → Privacy & Security → Open Anyway.

If macOS still blocks the app

Clear quarantine in Terminal:

xattr -cr /Applications/ClimaxDJ.app

Optional · stem separation runtime

On first stem use, a local runtime may install (~150–400 MB: Python venv + PyTorch + Demucs). Apple Silicon can use MPS (Apple GPU) when available.

Launch

Load music

Choose your music folder. Optional: Settings → Audio / VST scan.
