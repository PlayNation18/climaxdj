Install steps

Download the zip

arm64 or x64 from the macOS card above.

Unzip

You should see ClimaxDJ.app.

Move to Applications

Drag ClimaxDJ.app into Applications.

First launch

Right-click → Open → Open. Or Privacy & Security → Open Anyway. Fallback: xattr -cr /Applications/ClimaxDJ.app
