Install in four steps

Download

Get ClimaxDJ-Setup-4.3.0.exe (~72 MB) from GitHub Releases.

Install

Run the NSIS installer and pick a folder if prompted.

Launch

Open ClimaxDJ from Start menu or desktop shortcut.

Load music

Choose your music folder. Optional: Settings → Audio / VST scan.

  • Reverse, Ghost Notes, chord generator, pattern variation, time signatures, Deck→DAW, duplicates finder, crash recovery — implemented in ext45.js.
