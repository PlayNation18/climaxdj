Install instructions

  1. Download ClimaxDJ-Setup-4.3.0.exe.
  2. Run the NSIS installer (choose install directory if prompted).
  3. Launch ClimaxDJ from the Start menu / desktop shortcut.
  4. Select your music folder when asked.
  5. Optional: Settings → Audio / ASIO to register the ASIO bridge; Plugins / VST to scan VST3 folders.
