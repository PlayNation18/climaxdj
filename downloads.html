macOS

Installation guide

ClimaxDJ 4.7.0 for Mac ships as two architecture-specific zip files. Choose the one that matches your chip, then follow the Gatekeeper steps — the app is not Apple-signed.

Which version?

Apple Silicon vs Intel

  • Apple Silicon (M1, M2, M3, M4, M5, M6) → download the arm64 zip
  • Intel Mac → download the x64 zip

How to check: Apple menu → About This Mac → look at Chip (Apple M…) or Processor (Intel).

arm64 · Apple Silicon x64 · Intel
Requirements

macOS 11+

Built with Electron 33.2.1, which supports macOS Big Sur (11) and up — Intel and Apple Silicon. Universal binary is not provided (separate arm64 / x64 zips).

Not Developer ID signed · not notarized · cross-built from Linux. Early preview — feedback welcome.

Install steps

Download the zip

Get the arm64 or x64 zip for your Mac from the buttons above (~92–96 MB).

Unzip

Double-click the zip (or use Archive Utility). You should see ClimaxDJ.app.

Move to Applications

Drag ClimaxDJ.app into the Applications folder.

First launch (Gatekeeper)

Because the app is not Apple-signed: right-click ClimaxDJ.app → Open → confirm Open. Or System Settings → Privacy & Security → Open Anyway.

If macOS still blocks the app

Clear the quarantine flag in Terminal (paste carefully):

xattr -cr /Applications/ClimaxDJ.app

Then open ClimaxDJ again from Applications.

Optional · stem separation runtime

On first use of stem separation, ClimaxDJ can install a local runtime (Python venv + PyTorch macOS wheels + Demucs) — typically ~150–400 MB download. On Apple Silicon it uses the Apple GPU (MPS) when available; otherwise CPU. Models such as htdemucs download as needed.

Honesty · early Mac preview

  • Build 4.7.0 is an early unsigned Mac preview — not yet tested on every Mac model / macOS version.
  • Gatekeeper UX, audio routing, and Demucs/MPS behaviour may vary. Please report issues.
  • Also see MAC-INSTALL-4.7.0.txt on the release.

Choose your music folder. Optional: Settings → Audio / VST scan.
