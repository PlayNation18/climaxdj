    03 — ClimaxDJ Engine

    Built for audio.

    The technical foundation of the Windows desktop app — clearly marked as shipped, source-level, or future.

    Professional audio processingWeb Audio graph in-app + native helpers for stems/VST.
    Implemented
    WASAPI outputClimaxDJ itself plays out through Windows WASAPI with selectable device and buffer.
    Implemented
    ASIO driver (bridge)climax_asio.dll registers as “ClimaxDJ ASIO” for other hosts (ASIO→WASAPI). Not ClimaxDJ’s own output path; not yet verified against a third-party ASIO host.
    Source implementation
    MIDI integrationController learn, DDJ-FLX4 maps, DAW note input.
    Implemented
    VST3 hostingDesktop VST3 scan + live stream into Studio. VST2 listed but not hosted.
    Implemented (desktop)
    Low-latency ambitionsBuffer / samplerate controls exist; further ASIO-output work is future.

    What ships today

    Professional Mixing

    2/4 decks, crossfader modes, EQ, Sync, Slip, Auto-DJ with original tempo.

    Intelligent Analysis

    BPM, Camelot key, energy and harmonic library marking.

    Real-Time Waveforms

    Scrolling multi-band waveforms with beatgrid and hotcues.

    Studio Production

    Patterns, playlist, piano roll, session launcher, synths and sampler/slicer.

    AI Stems

    4-stem separation (vocals, drums, bass, melody) via optional Demucs engine.

    MIDI Controllers

    Learn mode and ready Pioneer DDJ-FLX4 mappings.

    VST3 + NI

    Finder and live hosting — Kontakt 7, Maschine 2, Massive X supported paths.

    Recording & Export

    DJ mix / mic / line recording, WAV song export and stems.

    4.5 creative tools

    Reverse, Ghost Notes, chords, pattern variation, time signatures, duplicates, crash recovery — in source.

    Made for the booth and the studio.
