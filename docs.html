Documentation

Quick start for ClimaxDJ 4.3.0 (Windows). This page is a light overview — the desktop app contains the full German UI help.

Install

  1. Download ClimaxDJ-Setup-4.3.0.exe from the download section.
  2. Run the NSIS installer and launch ClimaxDJ.
  3. Pick your music folder when prompted.

Core surfaces

  • DJ — dual decks, mixer, pads, library, Auto DJ.
  • DAW — patterns, playlist, mixer, sampler/slicer, VST, stems, WAV export.
  • SET — audio/ASIO, MIDI, library, automix, recording, plugins.

MIDI

Open MIDI → Connect. Pioneer DDJ-FLX4 maps play, cue, sync, EQ, pitch, faders, crossfader and hotcues. Other controllers: select a target and move the control to learn.
